# AI SEO Blog & Content Cluster Generator

## Project Overview

This project demonstrates how AI prompts can help plan SEO keywords, organize related blog topics, generate educational blog content, and review content quality for a sample IT training business.

## Business Scenario

**Pune Tech Skills Academy** is a fictional IT and computer training institute created for this project.

**Target Location:** Pune, Maharashtra, India

**Target Audience:** College students, graduates, beginners, job seekers, and working professionals.

## Project Objectives

- Develop reusable prompts for SEO content creation.
- Organize one pillar blog and five supporting blogs.
- Map keywords to search intent.
- Suggest internal linking opportunities.
- Incorporate relevant local SEO practices.
- Review content quality, readability, and factual accuracy.

## Tools and Methods

- Generative AI for prompt-based content drafting
- Keyword and search-intent mapping
- SEO title and meta description planning

- Manual content quality testing

## Limitations

- Suggested keywords have not necessarily been validated using live search-volume data.
- Proposed internal URLs must be checked before publication.
- All business-specific claims must be verified.
- SEO rankings, traffic, and conversions are not guaranteed.
