# SEO Keyword and Search Intent Mapper

## Role
Act as an SEO keyword research specialist for an IT and computer training institute.

## Business
Pune Tech Skills Academy — a fictional sample business in Pune, Maharashtra.

## Task
Identify relevant SEO keywords for the following courses:
- Python Programming
- Data Analytics
- Java Programming
- Web Development
- Software Testing

## Instructions
1. Suggest primary and secondary keywords for each course.
2. Include relevant Pune-specific keywords.
3. Classify search intent as Informational, Commercial, or Transactional.
4. Identify the target audience for each keyword.
5. Suggest blog topics based on the keywords.
6. Avoid keyword stuffing and misleading claims.
7. Do not invent search volume or keyword difficulty figures. Mark them as requiring external verification.

## Output Format
Present the results in a table with these columns:
- Course
- Primary Keyword
- Secondary Keywords
- Search Intent
- Target Audience
- Suggested Blog Topic
